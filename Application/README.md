# React Application Source Code

The React Vite application used in this Jenkins CI/CD project is available in a separate repository:

🔗 Source Code Repository:
https://github.com/snehabiswal006/react-eks-app

This repository contains the complete project documentation, architecture, screenshots, Kubernetes manifests, Docker configuration, and CI/CD pipeline details.

The Jenkins pipeline automatically pulls code from the react-eks-app repository, builds a Docker image, pushes it to Amazon ECR, and deploys it to Amazon EKS.
